# Documentation Index

## Purpose

This directory records TikLocal's key design decisions, release changes, and implementation constraints to reduce repeated discussion and regressions in later iterations.

## Documents

- [Web convergence plan](web-convergence-plan.md): implementation plan and delivery record for consolidating backend routes, shared resources, title handling, and experimental features.
- `docs/mixed-feed-design.md`: design and implementation notes for the mixed video and image Flow feed.
- `docs/flow-interaction-unification.md`: the shared interaction model for Flow, Library, and Favorites, including title entry points and asynchronous state rules.
- `docs/media-index-and-recommendation.md`: data flow and implementation boundaries for media indexing, safe synchronization, thumbnails, and local recommendations.
- `docs/native-local-app-architecture.md`: the LumaFold working brand, local-first native app architecture, offline import and playback, compatibility boundaries, and planned evolution.
- `docs/radio-native-client-architecture.md`: native navigation for the Radio module, TikLocal Server connectivity, queue restoration, player boundaries, and release path.
- `docs/radio-player-selection.md`: player candidates, licensing and New Architecture validation, and the `0.1.x` system media capability boundary.
- `docs/openrouter-image-to-video-research.md`: OpenRouter image-to-video research, proof-of-concept flow, and future product constraints.
- `docs/release_notes.md`: release history and unreleased changes.

The design and research documents above retain their original language until they are translated in a dedicated documentation pass.
